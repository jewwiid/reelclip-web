Étalonnage DJI Osmo Pocket sur iPhone — D-Log, D-Log M, D-Log 2

Un workflow pratique pour étalonner des rushs DJI Osmo Pocket sur iPhone. Couvre D-Log, D-Log M et D-Log 2 — les trois profils log que les Osmo Pocket 1, 2, 3 et 4 enregistrent — et comment les traiter avec des LUTs directement sur l'appareil.

August 25, 2026·9 min de lecture

La gamme DJI Osmo Pocket est l'une des caméras les plus populaires parmi les créateurs solo et les voyageurs, et pour cause : format compact, stabilisation excellente et qualité d'image sérieuse en profil gamma log. Le problème est que les rushs ressortent plats de la caméra, et les étalonner sur téléphone signifiait auparavant soit un éditeur très limité, soit un workflow de transfert et d'attente.

Ce guide détaille le workflow d'étalonnage sur appareil pour chaque génération DJI Osmo Pocket, du Pocket 1 original au Pocket 4. Le principe est le même pour toutes les générations : identifier le profil log, appliquer une LUT de transformation caméra pour revenir au Rec.709, puis superposer n'importe quel look créatif par-dessus.

Quel profil log votre Pocket enregistre-t-il ?

DJI a déployé trois profils log dans la gamme Osmo Pocket. Chacun capture plus de dynamique que le Rec.709, mais la courbe gamma diffère entre eux — une LUT qui convertit un profil ne donnera pas une conversion correcte pour un autre.

Osmo Pocket 1 — D-Log

L'Osmo Pocket original enregistre en D-Log 10-bit. C'est le premier profil log de DJI, conçu pour les workflows cinéma. Les rushs offrent le plus de marge de manœuvre de tous les profils DJI mais nécessitent aussi la LUT de conversion la plus précise. Des LUTs incorrectes donneront une dominante verte ou magenta.

Osmo Pocket 2 — D-Log (toujours)

Le Pocket 2 utilise la même courbe D-Log que l'original. La conversion est identique : toute LUT D-Log vers Rec.709 conçue pour le Pocket 1 fonctionnera ici.

Osmo Pocket 3 — D-Log M

Le Pocket 3 a introduit le D-Log M, une courbe légèrement plus indulgente. Les rushs restent plats à la sortie de caméra mais avec un peu plus de latitude dans les ombres, ce qui facilite la récupération de détails en post-production. La conversion est similaire au D-Log mais nécessite la LUT spécifique au D-Log M.

Osmo Pocket 4 — D-Log 2

Le Pocket le plus récent embarque le D-Log 2, conçu pour les pipelines HDR 10-bit. La conversion se rapproche d'une véritable courbe log cinéma. Traitez les rushs D-Log 2 comme vous le feriez avec l'ARRI LogC ou le Sony S-Log3 — il est conçu pour être étalonné, pas affiché directement.

Le workflow d'étalonnage sur appareil

Étape 1 : Importer les rushs

Transférez vos fichiers Pocket vers votre iPhone. La méthode la plus rapide est l'export de l'app DJI Mimo vers Photos, ou un import USB-C direct si votre Pocket le supporte. Une fois le fichier dans Photos ou Fichiers, ouvrez ReelClip et importez-le. Le fichier est copié dans le bac à sable privé de l'app — rien n'est téléchargé.

Étape 2 : Identifier le profil colorimétrique

ReelClip lit la balise de métadonnées du fichier et tente de détecter automatiquement le profil log. Si le fichier a perdu sa balise lors du transfert (fréquent avec les fichiers DJI), l'app vous laisse confirmer manuellement. Choisissez le profil correspondant à ce que vous avez tourné : DJI D-Log, DJI D-Log M, ou DJI D-Log 2.

Étape 3 : Appliquer la LUT de transformation caméra

ReelClip applique la LUT de transformation caméra intégrée correcte pour le profil sélectionné. Il s'agit de la conversion du gamma log vers le Rec.709. Le résultat devrait ressembler à un fichier vidéo normal : contraste, saturation et teintes de peau corrects.

Étape 4 : Superposer un look créatif par-dessus

Une fois la transformation caméra appliquée, vous pouvez empiler n'importe quelle LUT créative supplémentaire par-dessus. ReelClip supporte les LUTs .cube importées par l'utilisateur depuis l'app Fichiers. C'est ici que vous pouvez affiner un look spécifique — une émulation film, un étalonnage cinéma chaud, une ambiance caméra d'action froide. La LUT créative est appliquée avec une intensité que vous contrôlez, vous pouvez donc l'atténuer si elle est trop forte.

Étape 5 : Exporter

Enregistrez le clip étalonné dans Photos. La sortie est un fichier standard Rec.709 que n'importe quel éditeur peut lire. De là, vous pouvez le publier directement, l'éditer davantage, ou le partager via la feuille de partage iOS.

Pourquoi c'est important pour les utilisateurs d'Osmo Pocket

Le workflow traditionnel Pocket était : importer sur carte SD, copier sur ordinateur portable, ouvrir DaVinci Resolve, appliquer la LUT de conversion, étalonner, rendre, copier sur téléphone, publier. C'est un minimum de 30 minutes de traitement pour un seul clip.

Le workflow sur appareil est : extraire le fichier de la caméra avec DJI Mimo, importer dans ReelClip, appliquer la LUT, exporter. Cela prend deux minutes, et le fichier ne quitte jamais votre téléphone entre l'import et la publication. Pour les créateurs voyageurs, les tournages en mouvement et quiconque publie du contenu le jour même, c'est le workflow que vous voulez vraiment.
