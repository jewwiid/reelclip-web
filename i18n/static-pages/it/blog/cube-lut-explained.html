Cos'è un file LUT .cube? Formato, limiti di dimensione e come usarlo

.cube è il formato LUT universale. Questa guida spiega cosa contiene effettivamente un file .cube, i limiti di dimensione comuni (17, 33, 65) e come importarne uno su iPhone.

August 25, 2026·7 min di lettura

Un file .cube è il formato universale per le LUT di colore video (Look-Up Table). Se hai mai scaricato un pacchetto LUT o una gradazione colore da un creator online, è quasi certo arrivato come file .cube. Questa guida spiega cosa c'è effettivamente dentro, cosa significano i numeri delle dimensioni (17, 33, 65) e come usarne uno su iPhone.

Cosa significa "LUT"

LUT sta per Look-Up Table. Nella gradazione colore video, una LUT è un elenco di mappature da un colore di input a un colore di output. Il lettore video legge ogni pixel, cerca il suo colore nella tabella e lo sostituisce con il colore mappato. Applicata uniformemente su ogni fotogramma, una LUT ti offre una gradazione colore coerente.

Le LUT si dividono in due grandi categorie:

  • LUT 1D. Mappano ogni canale colore (rosso, verde, blu) in modo indipendente. Usate principalmente per semplici regolazioni di gamma e contrasto. Meno comuni oggi.
  • LUT 3D.Mappano un cubo colore tridimensionale (triplete RGB in, triplete RGB out). Queste sono ciò che le persone intendono quando dicono "una LUT" oggi. Possono esprimere qualsiasi trasformazione colore, inclusi look cinematografici creativi.

Il formato .cube supporta entrambe. La maggior parte dei file che incontrerai sono 3D.

Cosa c'è dentro un file .cube

Un file .cube è testo semplice. Puoi aprirlo in qualsiasi editor di testo e leggerlo. La struttura è simile a questa:

TITLE "My Film Look"
LUT_3D_SIZE 33
DOMAIN_MIN 0.0 0.0 0.0
DOMAIN_MAX 1.0 1.0 1.0

# A long list of RGB triplets, one per line.
# Each row is an output color, mapped from a position in a 3D color cube.
0.000000 0.000000 0.000000
0.031250 0.029167 0.026389
0.062500 0.058333 0.052778
...thousands more lines...
1.000000 1.000000 1.000000

Le prime righe sono metadati: un titolo, la dimensione del cubo colore 3D e l'intervallo di input. La maggior parte del file è un lungo elenco di triplette RGB — ogni possibile colore di input e cosa dovrebbe diventare.

Il numero della dimensione: cosa significano 17, 33 e 65

La riga LUT_3D_SIZE indica la risoluzione del cubo colore. Il numero è la dimensione di un lato — quindi un cubo 33 ha 33×33×33 = 35.937 voci, e un cubo 65 ha 65×65×65 = 274.625 voci.

Dimensioni comuni e cosa significano:

  • Cubo 17. 4.913 voci. La dimensione pratica più piccola. Adatta per trasformazioni di camera e look semplici. Dimensione file minuscola, caricamento rapido, leggermente meno preciso delle dimensioni maggiori.
  • Cubo 33. 35.937 voci. Il default per la maggior parte dei pacchetti LUT. La dimensione che la maggior parte dei creator spedisce e che la maggior parte degli editor imposta come default. Buon equilibrio tra precisione e prestazioni.
  • Cubo 65. 274.625 voci. Usato per emulazioni cinematografiche di alto livello dove le differenze di colore sottili contano. File più grande, più lento da analizzare, nessuna differenza visibile di qualità per la maggior parte dei footage.

Per la maggior parte dei creator, 33 è il punto ideale. La differenza di precisione tra 33 e 65 è invisibile sui display consumer, e i file cubo 65 sono circa 8 volte più grandi di quelli 33.

Dimensione file e limiti

Essendo testo semplice, i file .cube sono minuscoli. Un cubo 33 è solitamente sotto 1 MB; un cubo 65 arriva al massimo a circa 8 MB. L'editor nativo per iPhone ReelClip accetta file .cube fino a un limite di dimensione ragionevole (il suo parser rifiuta file troppo grandi da caricare in sicurezza) e supporta le dimensioni standard 17/33/65 più alcune varianti comuni.

Se mai vedi un file .cube che non si carica, la causa più comune è un'intestazione di tabella combinata non supportata (alcuni editor scrivono LUT 1D + 3D in un unico file). La soluzione è esportare solo la tabella 3D dallo strumento che l'ha creata.

Come importare e usare una LUT .cube su iPhone

Passo 1: Salva il file .cube sul tuo iPhone

Decomprimi il pacchetto LUT se necessario. Salva il file .cube in una posizione leggibile da iOS: File (sul dispositivo o iCloud Drive), Dropbox, Google Drive. La posizione esatta non importa — ReelClip lo legge da qualsiasi cartella raggiungibile dal selettore File.

Passo 2: Apri il video in ReelClip

Importa la clip che vuoi gradare. Se la clip è footage log (DJI D-Log, Apple Log, HLG), imposta prima il profilo colore camera così che ReelClip applichi la giusta trasformazione camera.

Passo 3: Importa la LUT

Nel pannello Look, tocca Importa LUT e seleziona il file .cube. ReelClip convalida l'intestazione, analizza le voci colore e lo aggiunge alla tua libreria LUT sul dispositivo. Il file rimane sul tuo telefono.

Passaggio 4: Applica e regola

Seleziona la LUT e regola il cursore dell'intensità. Sovrapponi un look creativo alla trasformazione della camera per gradazioni stilizzate, oppure applica solo la trasformazione della camera per una riproduzione del colore accurata.

Passaggio 5: Esporta

Salva la clip gradata in Foto. L'output è un file video standard Rec.709 con la LUT incorporata.

Problemi comuni dei file .cube

  • Tabelle 1D e 3D combinate. Alcuni editor scrivono entrambe in un unico file .cube. ReelClip rifiuta questi file e ti chiede di esportare solo la parte 3D.
  • Intervallo di dominio errato. La maggior parte delle LUT usa il dominio 0,0–1,0. Alcune LUT per camera più datate usano -0,1 a 1,1 (intervallo esteso per i highlight). Entrambi funzionano, ma l'editor deve applicare l'intervallo corretto.
  • File troncati. Se il file è stato interrotto durante il download, l'editor non può riempire le voci mancanti. Scaricalo di nuovo.
  • Dimensioni non supportate. Qualsiasi valore al di fuori di 2–65 (l'intervallo supportato da ReelClip) verrà rifiutato. Converti a 33 se hai una dimensione insolita.
